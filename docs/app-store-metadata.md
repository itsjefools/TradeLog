## 📝 App Description

### 日本語 (4000文字以内)

```
■ TradeLog — FXトレーダーのためのSNS × 取引記録

TradeLog は、FX取引の記録と分析、そしてトレーダー同士の交流ができる総合プラットフォームです。
取引を記録するだけでなく、勝率や P&L の推移を可視化し、コミュニティで戦略を共有しましょう。


■ 主な機能

【取引記録】
・通貨ペア、エントリー / エグジット価格、ロットサイズ、損益、メモを記録
・43以上の通貨ペアに対応、検索式入力で素早く選択
・お気に入りペア登録機能
・pips自動計算 (エントリー + エグジット + 方向 + ペアから算出)
・利確 / 損切りボタンで素早く入力

【分析ダッシュボード】
・月間 P&L、勝率、取引回数、平均pipsを一目で
・カレンダービューで日別の取引履歴を視覚化
・RR比 (リスクリワード)、平均P&Lなどの詳細指標

【ソーシャル機能】
・取引結果やトレード戦略を投稿
・フォロー / フォロワー機能
・いいね、コメント、リポスト、ブックマーク
・ハッシュタグ検索
・月間 P&L ランキング

【プロフィール】
・国旗付き国籍表示
・トレードスタイル (スキャルピング / デイトレード / スイング)
・本人確認バッジ
・公開取引履歴


■ こんな方におすすめ

・トレードの振り返りを習慣化したい
・自分の手法を発信したい
・他のトレーダーから学びたい
・コミュニティで切磋琢磨したい


■ プライバシーとセキュリティ

・取引データは安全に暗号化されて保管されます
・公開する取引は「共有」トグルで自由に選べます
・他のユーザーをブロック / 通報する機能あり


■ 多言語対応

日本語 / 英語 / ポルトガル語 / 中国語 / スペイン語


■ サポート

ご質問やフィードバックは trilionbrothers@gmail.com までお気軽にお寄せください。

TradeLog で、あなたのトレード人生を次のレベルへ。
```

## 📸 スクリーンショット計画

iPhone 6.9" (1290x2796) と iPhone 6.5" (1242x2688) で 5〜10枚必要。

### 推奨構成 (5枚)

1. **フィード**: 友人の取引結果と戦略投稿が並ぶ画面
   - キャッチコピー: "トレーダーが集うソーシャル"

2. **取引記録**: 通貨ペア検索 + エントリー入力中の画面
   - キャッチコピー: "ワンタップで取引を記録"

3. **分析ダッシュボード**: 月間 P&L + カレンダー
   - キャッチコピー: "あなたのトレードを可視化"

4. **月間ランキング**: トップ10表示
   - キャッチコピー: "コミュニティで切磋琢磨"

5. **プロフィール**: 国旗 + 認証バッジ + 統計
   - キャッチコピー: "あなたの戦績を世界へ"
